THREE-PAGE MEETING WEBSITE

Upload every file in this folder into the same cPanel public_html directory.

Flow:
1. index.html opens first.
2. Clicking Join Meeting opens teams_live_meeting.html.
3. teams_live_meeting.html redirects to meetingrd.html after 3 seconds.
4. meetingrd.html redirects to the configured Google Share page after another 3 seconds.

Keep female_hello.mp3 in the same folder as the HTML files.
HTTPS is required for browser camera access.
